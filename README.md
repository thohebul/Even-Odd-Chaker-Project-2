# 🔢 Even & Odd Checker Project #2

A simple and responsive **Even & Odd Checker** web application built using **HTML5, Bootstrap, and JavaScript**. Users can enter any number, and the application instantly determines whether it is **Even** or **Odd**.

---

## 🎯 How It Works

1. Enter any integer number.
2. Click the **Press Here** button.
3. The application instantly checks the number.
4. Displays whether the number is **Even** or **Odd**.
